Screen 4 · /method – Leitplanken + echte Kartenreise
Guardrails

Agents are fast.
The guardrails are the method.

Nothing ships by itself

Runs prepare everything, then stop at a column called “Go live?” with the exact steps written out. Release is a human decision. Every time.

Three runs, zero collisions

Up to three agents work in parallel. Each run claims the repos and devices it touches – a second run on the same repo waits in line.

Watchers on the shipping state

Tests that guard what goes to the store: production switches, page sizes, server version. A bundle that fails a watcher never gets built.

Sign-off that can't get lost

Human judgment is the bottleneck, so every review click is saved the moment it happens.

State lives in files

Every unattended job has a brief with work packages and checkboxes. If a run dies, the next one picks up where it stopped.

A card is a change, not a release

Changes collect on main. Builds, version numbers and store uploads happen only on a release button.
