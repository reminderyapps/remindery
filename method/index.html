Der Prozess

Die meisten Studios ergänzen ihren Prozess um KI.
Wir haben unseren um die KI herum gebaut.

Sechs Phasen. Jeder Step ist ein Agent mit klarer Rolle, versioniertem Skill und einer Definition of Done. Die Agents laufen autonom – der Gründer ist on the Loop und genau an drei Stellen in the Loop: beim Konzept, beim Sign-off und beim Go.

Control Plane

Ein Board.
Jeder Agent-Run startet hier.

Ein selbst gebautes Board ist das Cockpit. Der Gründer priorisiert per Drag & Drop, eine fertige Karte wird mit einem Klick zum Agent-Run. Jede Bewegung steht im Log.

▶ UmsetzenEine fertige Karte trägt ihren eigenen Prompt und ihr Arbeitsverzeichnis. Ein Klick startet einen Agent darauf.
Drei parallel, null KollisionenJeder Run belegt die Repos und Geräte, die er braucht. Ein zweiter Run im selben Repo stellt sich an – Überholen gibt es nicht.
Stopp bei „Go live?“Kein Run deployt einen Server, lädt in einen Store hoch oder veröffentlicht diese Website. Er schreibt die genauen Schritte auf und wartet.
🌙 FeierabendEin Knopf wartet auf laufende Jobs, startet einen Sicherungs-Agent, pusht alles – und fährt dann den Rechner herunter.

Automatisierungsgrad

Nicht alles soll allein laufen.

Ein Step steigt erst auf, wenn das Ergebnis des Agents bei gleichen Eingaben immer wieder mit dem menschlichen Urteil übereinstimmt. Manche Steps sollen bei „KI entwirft, Mensch entscheidet“ bleiben – Urteilskraft ist nicht das, was automatisiert wird, sondern das, wofür die Automatisierung da ist.

Leitplanken

Agents sind schnell.
Die Leitplanken sind die Methode.

Nichts geht von selbst live

Runs bereiten alles vor und halten bei „Go live?“ mit den genauen Schritten. Release ist eine menschliche Entscheidung, jedes Mal.

Eine Karte ist eine Änderung, kein Release

Änderungen sammeln sich auf main. Build, Versionsnummer und Store-Upload gibt es nur auf einen Release-Knopf.

Wächter auf dem Auslieferungszustand

Tests bewachen, was in den Store geht: Produktions-Schalter, Speicherseiten, Server-Stand. Schlägt einer an, wird das Bundle gar nicht erst gebaut.

Sign-off, das nicht verloren geht

Menschliches Urteil ist der Engpass – deshalb wird jeder Klick in einer Abnahme sofort gespeichert.

Zustand lebt in Dateien

Jeder unbeaufsichtigte Job hat eine Auftragsdatei mit Paketen und Haken. Bricht ein Run ab, macht der nächste dort weiter.

Context Engineering

Landkarten, Regeln und Lessons Learned liegen in versionierten Dateien, die jeder Agent liest – nicht im Kopf, nicht im Chatverlauf.
